APEX MOTORS SHOWROOM WEBSITE

Files:
- index.html: website structure
- styles.css: website styling and responsive layout
- script.js: category filters and test-drive form interactions

To run: keep all files in the same folder and open index.html in a web browser.
Note: car models, prices and specifications are illustrative demo content. The test-drive form is frontend-only and does not submit or store bookings.
